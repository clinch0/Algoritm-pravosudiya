# Проекты, обязательная подготовка и нормативный RAG

## Requirement: постоянный словарь проекта
Система MUST сохранять сущности и документы между перезапусками, использовать один заменитель для подтверждённой сущности и изолировать проекты по владельцу.
### Scenario: два документа
WHEN лицо встречается в двух документах одного проекта THEN заменитель одинаков; другой проект не использует его namespace.

## Requirement: обязательный шлюз
Система MUST обрабатывать JSON на сервере; готовый JSON от клиента не является доверенным. Изменение словаря MUST инвалидировать прежнее подтверждение. Детектор не гарантирует полноты и требует просмотра человеком.
### Scenario: изменение после просмотра
WHEN добавлен вариант имени после подготовки THEN отправка старого draft отклоняется.

## Requirement: источники и модель
Система MUST передавать модели подготовленный контекст и найденные источники. Неизвестные ссылки отклоняются. Отсутствие источников даёт явный отказ. Нулевая температура не является гарантией достоверности.
### Scenario: выдуманная ссылка
WHEN ответ содержит id вне найденного набора THEN ответ не принимается.

## Requirement: безопасное хранение
Сырые документы, запросы и словарь MUST храниться зашифрованно. Ключ и БД MUST сохраняться совместно в закрытой резервной копии. Доступ по другому owner отклоняется. DPAPI защищает ключ учётной записи Windows, но не от процесса под той же учётной записью.

## Requirement: документный retrieval
Система MUST выбирать фрагменты только после обфускации, ограничивать объём и сохранять ID/хеш. Источники дела не являются доказанными фактами; отсутствие совпадений не означает отсутствия факта.
### Scenario: нерелевантный документ
WHEN запрос касается частной жизни, а отдельный документ только поставки досок THEN нерелевантный документ не отправляется модели.

## Requirement: сохранение ответа
Система MUST хранить принятый ответ зашифрованно и показывать его при повторном открытии проекта. Изменение контекста делает ответ неактуальным. Исходные значения словаря и неизвестные токены в ответе отклоняются.
### Scenario: ответ после обновления словаря
WHEN найден новый вариант имени THEN прежний ответ не показывается и не восстанавливается как актуальный.
