# Контракт следующего этапа — ещё не реализован

Перед использованием обнаружь реальные инструменты сервера и их схемы. Предлагаемые имена: search_law, get_law_unit, resolve_law_version, get_case_context, search_case_documents, check_case_facts, get_statistics, submit_draft. Если их нет — вернись к действующему демонстрационному режиму SKILL.md.

Общий конверт межролевого результата: case_id, run_id, mapping_revision, document_revision, fact_revision, index_revision, producer_role, facts, evidence_refs, citations, unresolved. Не включай исходные ФИО, пути или карту восстановления. producer_role не является удостоверением полномочий.

Агент фактов читает подготовленные фрагменты своего дела и предлагает факты с evidence_ref; неоднозначные сведения остаются unresolved. Агент источников находит кандидатов, читает точный фрагмент, проверяет статус временного интервала и возвращает version_id/source_locator. Программная проверка применяется к подтверждённой ревизии фактов. Агент проверки сопоставляет результат с источником. Агент отчёта формирует черновик с исходными токенами, без автоматического назначения наказания.

При отсутствии источника не дополняй вывод правдоподобной нормой. Релевантность поиска не равна юридической применимости. Временная история может быть неполной; обратная сила требует отдельного рассмотрения. Допустимы только цитаты из реально полученных фрагментов с идентификаторами версии.

Токены другого дела, неизвестные токены и конфликт mapping_revision блокируют автоматическую выдачу восстановленного результата. Оркестратор запрашивает актуальную проекцию либо передаёт вопрос человеку. Сам агент не получает права вызвать восстановление или читать vault.
