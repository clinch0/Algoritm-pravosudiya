# SDD для команды

Выбран формат OpenSpec: требования и сценарии находятся в openspec/specs. Это начальный набор спецификаций, CLI OpenSpec пока не установлен. Spec Kit также подходит, но одновременно вести два источника требований не нужно.

Изменение начинается с проблемы, ожидаемого поведения и контрпримера. Затем обновляются спецификация, код, регрессионные проверки и описание результата. Для правового правила отдельно проверяются редакция, условия и исключения. Юридическая рецензия нужна и самой спецификации: зелёные тесты не подтверждают правильность нормы.

Источники: https://github.com/Fission-AI/OpenSpec и https://github.com/github/spec-kit .
