# Технические проверки безопасности

Актуальные результаты перечислены в [STATUS.md](STATUS.md), процесс и незакрытые контроли — в [SECURE_SDLC.md](SECURE_SDLC.md). Проверка зависимостей теперь завершена; предыдущие сетевые сбои сохранены во внутреннем журнале.

Bandit и pip-audit не заменяют модель угроз, DAST, проверку логики доступа и требований обработки данных. 186 регрессий, браузерный smoke и Docker restart подтверждают проверенные сценарии, а не промышленную готовность. SBOM содержит имена/версии 51 зависимости из lock. Локальный vault реализован, но отдельного защищённого процесса/управляемого KMS нет.
