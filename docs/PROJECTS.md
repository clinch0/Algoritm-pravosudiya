# Проектный интерфейс и локальная LLM

Главная страница: проекты. Старое демо проверки наказания: /demo. Создайте проект → добавьте вымышленный TXT/DOCX/PDF → проверьте словарь → введите запрос → подготовьте и проверьте JSON → отправьте.

Автоматически ищутся полные русские ФИО с отчеством, телефоны, почта, СНИЛС, отдельные паспортные/адресные формы. Иные сведения добавляются вручную; варианты склонения привязываются к сущности явно. Новая запись обновляет сохранённые проекции и отменяет прежние подтверждения. Замены читаемы: Гражданин А с коротким идентификатором проекта. Восстановление возвращает основное значение, не гарантируя исходное склонение.

Для LLM нужен работающий локальный сервер с маршрутом /v1/chat/completions. Установите и запустите выбранную модель отдельно, укажите VO_LLM_BASE_URL и VO_LLM_MODEL; ключ при необходимости — VO_LLM_API_KEY. В Docker адрес модели на хосте: http://host.docker.internal:11434/v1. Модель и оборудование в поставку не входят. Без конфигурации запрос подготавливается, ответ модели не имитируется.

Первый RAG ищет по четырём статьям Конституции (2,18,21,23) и передаёт источники вместе с обработанным контекстом модели. Ответ должен быть JSON с answer и citations. Неизвестные ссылки отклоняются; подтверждение смысла каждого утверждения пока остаётся за человеком. Полноценного гибридного поиска и независимой оценки ещё нет.

Корпус: data/law_seed.json. Добавляйте проверенные фрагменты с новым version id, источником, локатором и описанием редакции. Импорт: python tools/import_law_snapshot.py path/to/snapshot.json. Повтор того же снимка идемпотентен; изменение существующего id запрещено. Поиск через MCP: search_law/get_law_unit и ресурс law://unit/{unit_id}. История действия норм не считается подтверждённой автоматически.

Внешний DeepSeek API совместим по формату, но текущий продуктовый адаптер разрешает только локальные адреса. Тесты проекта работают без платного API и без модели. Ключ внешнего сервиса допустимо использовать в отдельно согласованном тесте с синтетикой; в Git его не добавляют. Прямой GigaChat требует отдельного адаптера авторизации — не заявлен реализованным.
